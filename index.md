# Název testu                      ← začíná nový test

? Otázka s výběrem                 ← otázka
+ správná možnost                  ← právě jedna +
- špatná možnost                   ← aspoň jedna -

? Volná otázka, hodnotím se sám    ← toto se bude využívat u psaných odpovědí, kde bude možné zapsat odpověď více způsoby např. vysvětlení elektromagnetu
= Praha                            ← správná odpověď (zobrazí se po odpovědi)
= hlavní město Praha               ← další správná varianta, zobrazí se také

? Volná otázka, kontroluje stránka
== 56                              ← uznána jen tato odpověď
== padesát šest                    ← případně další uznaná varianta
