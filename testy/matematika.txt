# Lomené výrazy test pátek

// ===== PODMÍNKY (DEFINIČNÍ OBOR) =====

? Určete podmínku, za které má smysl výraz 5/(x-3).
+ x ≠ 3
- x ≠ -3
- x ≠ 0
- x ≠ 5

? Určete podmínky, za kterých má smysl výraz (x+2)/(x²-4).
+ x ≠ 2 a zároveň x ≠ -2
- pouze x ≠ 2
- pouze x ≠ -2
- x ≠ 4

? Pro jakou hodnotu x nemá smysl výraz 3/(2x+6)?
+ x = -3
- x = 3
- x = -6
- x = 0

? Pro jakou hodnotu x nemá smysl výraz 4/(x-7)? Napište číslo.
== 7
== x=7
== x = 7

? Výraz 1/(x·(x+5)) nemá smysl pro:
+ x = 0 a x = -5
- pouze x = 0
- pouze x = -5
- x = 0 a x = 5

? Výraz (x²+1)/(x²+4) má smysl pro:
+ všechna reálná čísla
- x ≠ 2
- x ≠ 2 a x ≠ -2
- x ≠ 0
